# API сервиса заказов

## POST /orders
### Принимаем
- account_id - идентификатор клиента (>= 1)
- item_id - идентификатор товара (>= 1)
- quantity - кол-во единиц товара (>= 1)
### Отдаём
#### 201 - Успех
- order_id - идентификатор заказа (>= 1)
- account_id - идентификатор клиента (>= 1)
- item_id - идентификатор товара (>= 1)
- item_name - название товара
- quantity - количество единиц (>= 1)
- created_at - дата создания
#### 404 - Пользователь или товар не найден
- error_message
#### 422 - поля quantity нет, или оно меньше 1
- error_message
#### 400 - Невалидные данные в запросе
- error_massage

## GET /orders/{id},
### Принимаем
- order_id - идентификатор заказа
### Отдаём
#### 200 - Успех
- order_id - идентификатор заказа (>= 1)
- account_id - идентификатор клиента (>= 1)
- item_id - идентификатор товара (>= 1)
- item_name - название товара
- quantity - количество единиц (>= 1)
- created_at - дата создания
#### 404 - Заказ не найден
- error_message
#### 400 - Невалидные данные в запросе
- error_massage

## GET /orders?account_id=
### Принимаем

- item_name - название товара

- created_at - дата создания
#### 404 - Пользователь не найден
- error_message
#### 400 - Невалидные данные в запросе
- error_massage
