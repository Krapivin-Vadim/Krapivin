# API сервиса заказов

Все ошибки возвращаются в виде JSON с полем `detail` (так же, как в сервисе клиентов).

## POST /orders — создать заказ

### Приходит
- `account_id` — номер клиента (целое число)
- `item` — что заказали (непустая строка, до 120 символов)
- `quantity` — сколько единиц (целое число, не меньше 1)

### Ответ
**201** — заказ создан. Карточка заказа:
- `id` — номер заказа
- `account_id` — номер клиента
- `item` — что заказали
- `quantity` — сколько единиц
- `created_at` — дата и время создания

### Ошибки
- **422** — нет одного из полей, поле неправильного типа, `item` пустой или `quantity` меньше 1
- **404** — клиента с таким номером нет, в `detail` указан номер клиента

## GET /orders/{id} — получить заказ

### Приходит
- `id` — номер заказа в адресе (целое число)

### Ответ
**200** — карточка заказа:
- `id`, `account_id`, `item`, `quantity`, `created_at`

### Ошибки
- **404** — заказа с таким номером нет, в `detail` указан номер, который искали
- **422** — `id` не является целым числом

## GET /orders?account_id= — список заказов клиента

### Приходит
- `account_id` — номер клиента (целое число), в параметре запроса
- `limit` — сколько заказов вернуть, от 1 до 200, по умолчанию 50
- `offset` — сколько заказов пропустить, не меньше 0, по умолчанию 0

### Ответ
**200** — список карточек заказов только этого клиента, по порядку создания. Каждая карточка:
- `id`, `account_id`, `item`, `quantity`, `created_at`

Если у клиента нет заказов, возвращается пустой список `[]` и тоже код 200.

### Ошибки
- **422** — `account_id` не указан или не число, `limit` вне диапазона 1–200, `offset` меньше 0
